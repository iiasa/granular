GRANULAR Typology of Rural Europe - Dataset Description=========================================================This GeoTIFF contains the GRANULAR Typology of Rural Europe. This is a territorialtypology developed by Nordregio in the GRANULAR project, funded by Horizon Europe(Grant agreement ID: 101061068). The typology is designed and the EU grid level, focusing on rural grid cells (mostly low density cells), as defined by the degree of urbanisation classification (DEGURBA 2021, Level 2). The rural typology is hence incremental and complementary in relation to DEGURBA. The classification was performed INDEPENDENTLY on each DEGURBA rural Level 2 class.This was done by applying a K-means clustering algorithm on a set of six indicators reflecting topography, landscape modification, built environment, population dynamics and accessibility to urban areas of different size. In this process, each grid cell was assigned a CODE corresponding to one of six newly-developed 'Level 3 GRANULAR classes', as detailed below. CELL VALUES-----------The raster attribute CODE takes one of the following integer values:3111, 3112, 3121, 3122, 3131, 3132CLASS HIERARCHY--------------- +---------------------------------------------+  | Level: 1 (DEGURBA 2021)
